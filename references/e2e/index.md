# E2E 工具路由与上报

> Pm 与 Qa 共用的 E2E 工具事实源。Pm 调度 Qa 时，除注入 `references/qa-prompt.md` 外，会一并注入本文件与按被测形态选定的工具说明文件。

## 场景路由表

E2E 工具按**被测目标形态**选择，禁止不区分场景一律使用同一工具。判定依据是「访问方式」而非页面风格：

| 场景 | 工具 | 说明文件 |
| ---- | ---- | -------- |
| PC Web 页面（URL 可访问的页面，含移动端风格的 H5 页面） | WDIO（WebDriverIO） | `e2e/wdio.md` |
| Electron 桌面应用 | WDIO（`@wdio/electron-service`） | `e2e/wdio.md` |
| Tauri 桌面应用 | WDIO（`@wdio/tauri-service`） | `e2e/wdio.md` |
| 移动端（iOS/Android 真机或模拟器，经 Appium） | WDIO MCP（`@wdio/mcp`） | `e2e/wdio-mcp.md` |

**核心原则：被测应用是什么平台，E2E 就必须在该平台的真实运行上下文中执行，禁止跨上下文取巧**——PC Web 在真实浏览器中访问目标 URL；Electron 由 electron service 拉起真实应用进程测试，浏览器里打开的渲染页面 / dev URL 不是 Electron 上下文；Tauri 由 tauri service 拉起真实应用二进制测试，浏览器里打开的前端页面不是 Tauri 上下文；移动端在真机/模拟器中测试，桌面浏览器的视口模拟不是移动端上下文。

## 共通执行规范

适用于所有工具：

- **一次 E2E 一次完整生命周期，切忌中途断开重连或遗留进程**：交互式工具（WDIO MCP）为建立会话 → 打开目标页面 → 操作 → 关闭会话，恰好一对开闭；WDIO 为初始化 `e2e/` 工作区 → 编写 spec → 一次 `wdio run` 完成全部操作，runner 结束后自动回收其拉起的浏览器与应用进程。
- **浏览器必须以有头模式运行**：无头模式的渲染问题（视口/布局差异、懒加载与动画不触发等）会使页面表现与真实用户所见不符、测试结果与截图证据不可信。启动配置见各工具说明文件。
- **交互前先获取真实元素标识再操作**，不要凭空猜测元素。获取方式见各工具说明文件。
- **截图证据必须落盘**为 `<迭代目录绝对路径>/evidence-N.png`，至少 1 张。落盘命令见各工具说明文件；若当前环境无法落盘，在报告中注明并以对话内截图为证。
- **测试结束不留残留进程**：交互式工具关闭会话；WDIO 由 runner 结束时自动回收，无须手动清理。

## Pm 上报处理流程

Qa 上报工具不可用时，或 Pm 调度 Qa 前确认工具可用性时，按以下流程处理：

1. **PC Web / Electron / Tauri 场景（wdio 环境不可用）**：如 Node/npm 缺失、依赖安装失败（网络受限）等。询问用户是否准备环境。WDIO 依赖由 Qa 在迭代目录的 `e2e/` 工作区内安装（`npm install` 属短时命令），不写入项目目录；Node 环境缺失则需用户自行安装。
2. **Electron 场景（应用入口未提供）**：由 Pm 从项目配置（如 `package.json` 的 `main`、构建产物入口）解析应用主进程入口与所需启动参数，将绝对路径告知 Qa。
3. **Tauri 场景（应用二进制未构建）**：构建命令（如 `npm run tauri build`、`cargo build`）耗时长，Qa 不得执行。由 Pm 委托 Dev 执行构建，或请用户手动构建；Pm 确认产物存在后将二进制绝对路径告知 Qa。
4. **移动端场景（WDIO MCP 未配置）**：告知用户当前环境未配置移动端 E2E 工具，询问是否现在配置 `@wdio/mcp`（WebDriverIO 官方 MCP server，支持 iOS/Android 真机与模拟器）。用户同意则按当前 agent 工具自身的 MCP 配置方式引导注册，Pm 不预设、不写死任何工具的具体配置细节；建议注册在用户级/工具级配置中，保持项目目录零侵入。配置生效可能需要重启会话——工作流状态已持久化在 `state.md`，重启后重新触发本 skill 即可按「中断恢复」续接，然后重新调度 Qa。
5. **用户拒绝安装/配置**：通知 Qa 按「E2E 降级模式」继续验收——功能性、视觉设计两维度不评分并注明原因，产品完整性与代码质量照常评分，迭代不因此判不通过，验收责任转移至用户 UAT。降级不消耗退化计数。
