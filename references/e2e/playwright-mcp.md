# Playwright MCP 使用说明

适用场景：**PC Web 页面**（URL 可访问的页面，含移动端风格的 H5 页面）、**Electron 桌面应用**（连接已运行的真实应用）。场景路由见 `e2e/index.md`。

## 工作方式

Playwright MCP（`@playwright/mcp`，微软官方）以**自然语言驱动交互式会话**方式执行 E2E：打开目标 → 操作 → 截图 → 关闭浏览器。测试动作经 MCP 工具调用完成（页面结构获取、点击、输入、截图等），**不编写测试脚本**。工具清单与参数由当前环境的 MCP 工具列表随版本自描述，本文件不固化任何工具名与参数。

## 用法事实源

Playwright MCP 用法以官方文档为唯一事实源：`https://github.com/microsoft/playwright-mcp`（README 含全部工具清单与配置项）。「先查文档、禁止凭记忆调用」规则见 `e2e/index.md` 共通规范。

## 测试代码零落盘

- E2E 全程经 MCP 工具调用完成，禁止向项目目录写入任何测试代码或脚本文件。
- 禁止以「写入项目目录 + 修改项目 `.gitignore` 排除」的方式变通。
- 工具返回的生成代码（codegen / 录制产物）不作为交付物；确需保留时只写入 `<迭代目录绝对路径>`（与截图证据同级）。

## 场景要点

### PC Web（含 H5）

- 以浏览器访问目标 URL。目标 URL 从项目配置 / AGENTS.md 获取，或请 Pm 向用户确认。
- dev server 未启动时**不得自行启动**（Bash 安全原则），在报告中注明并上报 Pm。
- 测 H5 页面可用移动视口 / 设备模拟，但这只是视口模拟，**不得以此替代真机移动端 E2E**。

### Electron

- 被测应用须已以**远程调试端口**运行（由用户或 Pm 侧启动），Playwright MCP 经 CDP 端点连接该**真实应用进程**执行测试；调试端点信息由 Pm 提供。
- **不执行任何应用启动命令**：应用未运行或端点未提供时，向 Pm 上报等待处理。
- **禁止改为浏览器打开渲染页面 / dev server URL 冒充 Electron E2E**——浏览器上下文没有主进程、IPC、Node 集成与原生窗口行为，结论不能代表应用真实表现。

## 操作环节

一次 E2E 按以下环节执行，全部操作在同一次会话内完成：

1. **打开目标**：PC Web 导航至目标 URL；Electron 经调试端点连接已运行的应用后直接操作应用窗口页面。浏览器以**有头模式**运行——若工具配置为无头，先按官方文档调整配置再执行（Playwright MCP 默认有头）。
2. **获取页面结构**：先获取当前页面的可访问性快照（snapshot），据此定位**真实元素**，不得凭空猜测元素。
3. **执行操作**：模拟真实用户操作（导航、输入、点击、滚动），走完本迭代的核心用户路径，记录所有异常行为和 bug。
4. **截图落盘**：关键步骤截图并保存为 `<迭代目录绝对路径>/evidence-N.png`，至少 1 张。
5. **关闭会话**：E2E 结束后关闭浏览器，不留残留进程。

## 可用性检测

开始 E2E 前确认以下各项，任一不满足则向 Pm 上报：

- 当前环境已配置 Playwright MCP（可用工具列表中存在浏览器操作类——导航 / 页面快照 / 截图——工具）。
- Electron 场景：Pm 已提供调试端点信息，且被测应用已以远程调试端口运行。

## 证据落盘

截图保存为 `<迭代目录绝对路径>/evidence-N.png`，至少 1 张，报告中列出文件名；截图工具支持指定文件名时直接以绝对路径保存，仅返回图像数据时将其解码写入文件。
