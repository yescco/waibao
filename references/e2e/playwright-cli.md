# Playwright CLI 使用说明

适用场景：**PC Web 页面**（URL 可访问的页面，含移动端风格的 H5 页面）、**Electron 桌面应用**（连接已运行的真实应用）。场景路由见 `e2e/index.md`。

## 工作方式

Playwright CLI（`@playwright/cli`，命令 `playwright-cli`，微软官方）是面向编码 agent 的交互式命令行工具，以**逐步探索**方式执行 E2E：打开 / 附加目标 → 获取页面快照 → 按快照中的元素标识执行确定性操作 → 截图 → 关闭 / 脱离。测试动作即时执行、即时反馈，**不编写测试脚本**。命令与参数由官方文档随版本维护，本文件不固化任何命令名与参数。

## 用法事实源

Playwright CLI 用法以官方文档为唯一事实源：`https://playwright.dev/agent-cli/`（含安装、命令参考与各场景指南）。「先查文档、禁止凭记忆调用」规则见 `e2e/index.md` 共通规范。

## 测试代码零落盘

- E2E 全程以即时执行的命令完成，禁止向项目目录写入任何测试代码或脚本文件。
- 禁止以「写入项目目录 + 修改项目 `.gitignore` 排除」的方式变通。
- 工具的生成代码 / 录制能力不作为交付物；确需保留的产物只写入 `<迭代目录绝对路径>`（与截图证据同级）。

## 场景要点

### PC Web（含 H5）

- 以浏览器打开目标 URL。目标 URL 从项目配置 / AGENTS.md 获取，或请 Pm 向用户确认。
- dev server 未启动时**不得自行启动**（Bash 安全原则），在报告中注明并上报 Pm。
- 测 H5 页面可用移动视口 / 设备模拟，但这只是视口模拟，**不得以此替代真机移动端 E2E**。

### Electron

- 被测应用须已以**远程调试端口**运行（由用户或 Pm 侧启动），Playwright CLI 经 CDP 端点连接该**真实应用进程**执行测试；调试端点信息由 Pm 提供。
- **不执行任何应用启动命令**：应用未运行或端点未提供时，向 Pm 上报等待处理。
- **禁止改为浏览器打开渲染页面 / dev server URL 冒充 Electron E2E**——浏览器上下文没有主进程、IPC、Node 集成与原生窗口行为，结论不能代表应用真实表现。

## 操作环节

一次 E2E 按以下环节执行，全部操作在同一会话内完成：

1. **打开目标**：PC Web 打开浏览器并导航至目标 URL；Electron 经调试端点连接已运行的应用后直接操作应用窗口页面。浏览器以**有头模式**运行——工具默认无头时显式指定有头（参数以官方文档为准）。
2. **获取页面结构**：先获取当前页面的可访问性快照，据此定位**真实元素**，不得凭空猜测元素。
3. **执行操作**：模拟真实用户操作（导航、输入、点击、滚动），走完本迭代的核心用户路径，记录所有异常行为和 bug。
4. **截图落盘**：关键步骤截图并保存为 `<迭代目录绝对路径>/evidence-N.png`，至少 1 张。
5. **收尾**：自己启动的浏览器关闭；经附加连接的外部实例（如 Electron 应用）只脱离、不关闭。不留残留进程。

## 可用性检测

开始 E2E 前确认以下各项，任一不满足则向 Pm 上报：

- 当前环境已安装 Playwright CLI（`playwright-cli` 命令可执行，具体检测方式以官方文档为准）。
- Electron 场景：Pm 已提供调试端点信息，且被测应用已以远程调试端口运行。

## 证据落盘

截图保存为 `<迭代目录绝对路径>/evidence-N.png`，至少 1 张，报告中列出文件名；截图仅返回图像数据时将其解码写入文件。
