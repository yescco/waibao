# WDIO MCP 使用说明

适用场景：**PC Web 页面**（URL 可访问的页面，含移动端风格的 H5 页面）、**Electron 桌面应用**、**移动端**（iOS/Android 真机或模拟器，经 Appium——唯一支持真机/模拟器的通道）。场景路由见 `e2e/index.md`。

## 工作方式

WDIO MCP（`@wdio/mcp`）是 WebdriverIO 官方的 MCP server，以**交互式会话**方式执行 E2E：启动会话 → 打开目标 → 操作 → 截图 → 关闭会话。工具清单与参数由当前环境的 MCP 工具列表随版本自描述，本文件不固化任何工具名与参数。

## 用法事实源

WDIO 用法以官方文档为唯一事实源，检索入口与「先查文档、禁止凭记忆调用」规则见 `e2e/index.md` 共通规范。

## 场景要点

### PC Web（含 H5）

- 以浏览器会话访问目标 URL。目标 URL 从项目配置 / AGENTS.md 获取，或请 Pm 向用户确认。
- dev server 未启动时**不得自行启动**（Bash 安全原则），在报告中注明并上报 Pm。
- 测 H5 页面可用移动视口 / 设备模拟，但这只是视口模拟，**不得以此替代真机移动端 E2E**。

### Electron

- 由 Electron 会话直接拉起**真实应用进程**；项目根目录与应用入口信息由 Pm 提供。
- **禁止改为浏览器打开渲染页面 / dev server URL 冒充 Electron E2E**——浏览器上下文没有主进程、IPC、Node 集成与原生窗口行为，结论不能代表应用真实表现。

### 移动端

- iOS/Android 真机或模拟器，经 Appium；驱动与环境由工具管理，前提是目标设备与应用已就绪。
- 桌面浏览器的视口模拟不是移动端上下文，禁止冒充。

## 操作环节

一次 E2E 按以下环节执行，全部操作在同一次会话内完成：

1. **启动会话**：按被测形态启动对应平台会话（浏览器 / Electron / 移动端）。浏览器会话必须以**有头模式**启动——若工具默认无头，启动时显式关闭（参数以工具自描述为准）。
2. **打开目标**：PC Web 导航至目标 URL；Electron 由会话拉起应用后直接操作应用窗口页面；移动端加载目标应用。
3. **获取页面结构**：先获取当前页面的结构化信息（可交互元素、可访问性树等），据此定位**真实元素**，不得凭空猜测元素。
4. **执行操作**：模拟真实用户操作（导航、输入、点击、滚动），走完本迭代的核心用户路径，记录所有异常行为和 bug。
5. **截图落盘**：关键步骤截图并保存为 `<迭代目录绝对路径>/evidence-N.png`，至少 1 张。
6. **关闭会话**：E2E 结束后关闭会话，不留残留进程。

## 可用性检测

开始 E2E 前确认以下各项，任一不满足则向 Pm 上报：

- 当前环境已配置 WDIO MCP（可用工具列表中存在会话类——启动 / 关闭会话——工具）。
- Electron 场景：Pm 已提供项目根目录与应用入口信息。

## 证据落盘

截图保存为 `<迭代目录绝对路径>/evidence-N.png`，至少 1 张，报告中列出文件名；若截图工具仅返回图像数据，将其解码写入文件。
